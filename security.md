# Security review

The dumbdock security review now lives in the documentation site:

**https://jordantrizz.github.io/dumbdock/reference/security**

It holds the point-in-time review (2026-07-01) with findings by severity, the
addenda for the issues and storage workflows, positive observations, and the
remediation checklist.

Per-finding remediation status — what was fixed, and when — is recorded in
[`AGENTS.md`](AGENTS.md).

For anything else, start at
[the documentation](https://jordantrizz.github.io/dumbdock/).
