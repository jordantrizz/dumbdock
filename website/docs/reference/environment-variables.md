---
title: Environment variables
description: Every environment variable dumbdock reads, with its default and what it changes.
---

| Variable | Default | Description |
|----------|---------|-------------|
| `DOCKER_SOCK` | `/var/run/docker.sock` | Path to the Docker socket |
| `LISTEN_ADDR` | `:8080` | HTTP listen address; wins over `DUMBDOCK_PORT` |
| `DUMBDOCK_PORT` | `8080` | Port the app listens on when `LISTEN_ADDR` is unset, and the default host port in `docker-compose.yml.example` (the container always listens on 8080 there) |
| `POLL_INTERVAL` | `10s` | How often to poll Docker for container changes |
| `DUMBDOCK_CONFIG` | `/config/dumbdock.json` | Path to the JSON override config file |
| `DUMBDOCK_URL` | *(empty)* | Public URL of the dashboard, used in alert links |
| `NTFY_TOPIC` | *(empty)* | ntfy.sh topic for push notifications |
| `GOTIFY_URL` | *(empty)* | Gotify server URL |
| `GOTIFY_TOKEN` | *(empty)* | Gotify app token |
| `ALERT_COOLDOWN` | `5m` | Minimum time between consecutive alert batches |
| `AUTO_DETECTION` | `true` | Enable automatic icon detection for unlabeled containers |
| `AUTODETECT_GROUP_NAME` | `"Auto Detected"` | Group name for auto-detected containers |
| `AUTO_DETECTION_SERVICE_BLACKLIST` | `"server,db,app"` | Compose service names skipped when matching by service name; generic names are unreliable, and the container still goes through the other fallbacks |
| `CONTAINER_BLACKLIST` | *(empty)* | Comma-separated container names to hide entirely, e.g. `"dumbdock","traefik"` |
| `DUMBDOCK_UPDATE_CHECK` | `true` | Check Docker Hub and GHCR for newer digests of each image tag; also `updateCheck` in the config file |
| `DUMBDOCK_UPDATE_INTERVAL` | `6h` | How long a successful update check is cached |
| `DUMBDOCK_PASSWORD` | *(empty)* | Dashboard password. Basic auth with `http-auth` (any username), login-form password with `web-auth`. Auto-generated by `./control.sh setup`; random and logged once when empty. |
| `DUMBDOCK_AUTH_MODE` | `web-auth` | `none`, `http-auth`, or `web-auth`; overrides `authMode` |
| `DUMBDOCK_STATE_DIR` | `/data` | Persisted runtime state: `issues-acknowledged.json` and `backup-reports.json` (mode `0600`). Mounted as the `dumbdock-data` volume in Compose. |
| `DUMBDOCK_CONTAINER_ROOT` | `/opt/containers` | Where compose projects are expected to live; also `storage.containerRoot` |
| `DUMBDOCK_DATA_ROOT` | `/srv/containers` | Where persistent data is expected to live (`root/project/service/`); also the default evidence root and `storage.dataRoot` |
| `DUMBDOCK_BACKUP_ROOT` | value of `DUMBDOCK_DATA_ROOT` | Read-only path scanned for `project/service/backups/` artifacts; mount it into the container at the same path; also `storage.backupRoot` |
| `DUMBDOCK_BACKUP_MAX_AGE` | `26h` | Default freshness window for a required backup; overridden per dataset by `dumbdock.backup.max-age` or `storage.backups.project/service.maxAge` |
| `DUMBDOCK_BACKUP_SCAN_INTERVAL` | `5m` | How often inspects, the SQLite scan, and evidence collection run; mounts and labels are still read on every poll |
| `DUMBDOCK_BACKUP_TOKEN` | *(empty)* | Bearer token that lets a host script POST to `/api/backups/report` without a session. Grants report-write only; redacted in the startup log. |
| `TRAEFIK_API_URL` | *(empty)* | Explicit Traefik API base URL, overriding auto-discovery |
| `TRAEFIK_API_TOKEN` | *(empty)* | Bearer token for the Traefik API; also `traefikAPIToken` in the config file |
| `TRAEFIK_API_USER` | *(empty)* | Username for Traefik Basic auth |
| `TRAEFIK_API_PASS` | *(empty)* | Password for Traefik Basic auth |
| `DUMBDOCK_INTEGRATION_<ID>_ENABLED` | *(unset)* | Turn an integration on or off even when its container is detected (`traefik`, `watchtower`, `prunemate`) |
| `DUMBDOCK_INTEGRATION_<ID>_CONTAINER` | *(unset)* | Pin one container by name and treat it as this integration, even when its image does not match |
| `DUMBDOCK_INTEGRATION_<ID>_URL` | *(unset)* | Poll this API endpoint instead of auto-detecting one; `http`/`https` only, link-local addresses refused |
| `DUMBDOCK_INTEGRATION_<ID>_TOKEN` | *(unset)* | Bearer token for the integration API; sent as a header and never logged |
| `DUMBDOCK_INTEGRATION_<ID>_USER` / `_PASS` | *(unset)* | Basic-auth credentials for the integration API |
